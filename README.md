Enter# Vodafone Ramadan Cards - OROR 🎁

موقع لسحب وشحن كروت رمضان من فودافون بطريقة سهلة وسريعة.

## المميزات ✨

- ✅ **تسجيل دخول آمن** - باستخدام بيانات فودافون الخاصة بك
- ✅ **عرض الكروت المتاحة** - مع تفاصيل كل كارت
- ✅ **شحن يدوي** - نسخ كود الشحن واستخدامه من هاتفك
- ✅ **شحن مباشر** - تفعيل الكارت مباشرة من الموقع
- ✅ **تصميم متجاوب** - يعمل على جميع الأجهزة
- ✅ **واجهة عربية** - 100% باللغة العربية

## كيفية الاستخدام 📱

1. افتح الموقع: `https://OROR.github.io/vodafone-cards`
2. سجل الدخول برقم فودافون وكلمة المرور
3. اختر طريقة الشحن المناسبة
4. استمتع بكروت رمضان!

## التقنيات المستخدمة 🛠️

- HTML5
- CSS3 (مع Flexbox و Grid)
- JavaScript (ES6+)
- Font Awesome للأيقونات
- Google Fonts (Cairo)
